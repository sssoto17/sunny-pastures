## Proposed issues (not filed)

**A. Prevent closes with work left: foreign keywords and post-merge criteria**

- Type `chore`, `area:ci-cd`, M4, P1, Size S.
- Acceptance criteria:
  - [ ] `guard / pr-body` fails when a closing keyword names an issue that isn't the PR's own (the
        issue in its title or branch), including inside code spans and quotes, and names the line.
  - [ ] It fails `Closes #N` when #N has an unticked box that ends in `(after merge)`, and says to
        use `Part of #N`.
  - [ ] `docs/agents/issue-tracker.md` says to mark a criterion only the admin can show after merge
        with `(after merge)`.
  - [ ] Fixtures: #426's body (fails on #386) and #448's against #107's criterion 5 (fails).

**B. Review worktrees at one fixed path**

- Type `chore`, `area:tools`, M4, P1, Size XS. Split from #290 item 4.
- Acceptance criteria:
  - [ ] `REVIEW.md` "Reproduce, then report" uses one fixed absolute path that's the same inside and
        outside the sandbox, in place of `$TMPDIR`, and every command starts with `cd <path> && `.
  - [ ] The reviewer brief in the `/today` skill points to it.
  - [ ] The PR carries `review:admin` if `REVIEW.md` is code-owned.

**C. Actions pins match the allowed-actions list, and a stopped reviewer is noticed**

- Type `chore`, `area:ci-cd`, M4, P1, Size S. Split from #290 item 3.
- Acceptance criteria:
  - [ ] The allowed-actions list lives in a repo file, and a setup script applies it to the repo
        settings.
  - [ ] A CI job fails when a workflow's `uses:` SHA isn't in that file, so a Dependabot bump like
        #261 or #479 goes red instead of merging.
  - [ ] A `startup_failure` of `review.yml` posts a comment on #55 (or another place the admin
        reads).

**D. PR bodies stay true to the head**

        (Outcomes 5, 15 Nov).

**E. A script for throwaway stacks**
