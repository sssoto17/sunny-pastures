## Proposed issues (not filed)

**A. Refuse a sandboxed git update that touches `.claude/`**
- Type `chore`, `area:tools`, M3, P1, Size S.
- Acceptance criteria:
  - [ ] A `PreToolUse` hook denies `git pull`, `git merge` and `git rebase` when running in the
        sandbox and `git diff --name-only HEAD <incoming> -- .claude/` lists any path, with a
        message that gives the command to run on the host.
  - [ ] It applies in the main folder and in lane worktrees, and skips remote sessions like the
        other hooks.
  - [ ] Tests beside it, as in `block-branch-switch.test.sh`, cover pull, merge, `--ff-only` and
        an incoming range with no `.claude/` change (allowed).
  - [ ] `sandbox.md` points to the hook instead of the manual pre-check.
  - [ ] The PR carries `review:admin` (`.claude/hooks/` is code-owned).

**B. Catch issues closed early or left unlinked**
- Type `chore`, `area:ci-cd`, M3, P1, Size S.
- Acceptance criteria:
  - [ ] A PR job fails when a body that says `Part of #N` also has a closing keyword (close,
        closes, closed, fix, fixes, fixed, resolve, resolves, resolved) followed by `#N`, anywhere
        in the body, and names the line.
  - [ ] An `issues: closed` job comments the issue's unticked boxes, if any, and changes nothing
        else.
  - [ ] `CONSTRAINTS.md` "Split size" says to describe later parts without the keyword.
  - [ ] Tests with fixture bodies, including #131's table and #245's body.

**C. The floor guard reports spent Exceptions rows**
